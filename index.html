Science Olympiad · Bungee Drop Oct 2024 – Apr 2026

Predictive Bungee Stretch Model

Bungee Drop scores how close a dropped mass comes to a target, with the height and mass revealed on competition day. I built a model that picks the bungee configuration for combinations it has never seen.

  • Tested bungee materials through repeated drops, measuring consistency, durability, and stretch, and logged 300+ data points (height, mass, cord length).
  • Built the predictive model in Python with scikit-learn and Matplotlib, using Excel and Desmos to fit and check it.
  • At competition, predicted bungee behavior within 10 cm, for a Regional 2nd place medal and a State 7th place finish.
